# Product purpose
SkillBridge AI helps Malaysian candidates and employers compare practical competencies through transparent job and resume intelligence.

# Primary user
A fresh graduate or career changer using a phone or laptop to understand job fit, improve a resume, and choose the next useful skill to build.

# Principles
1. Explain the score before celebrating it.
2. Skills open the door; people make the decision.
3. The next useful action outranks decorative analytics.
4. Demonstration data must look and read like demonstration data.

# Success metric
A candidate identifies their strongest opportunity, highest-priority documentation issue, and next useful skill within one minute.

# Out of scope
- Automated candidate rejection
- Claims that self-assessment is verified
- Live labor-market statistics
- Paid external AI dependencies

# Learned constraints
- **2026-10-16** — Use a nude, warm beige, taupe, and coffee-brown identity across every surface. Purple, neon, cool corporate blue, and pure-black dashboard treatments are not part of the brand.
- **2026-10-16** — Typography uses Instrument Sans for product clarity and Fraunces for the landing hero’s editorial voice. Inter, Arial, and default system stacks are intentionally excluded.
- **2026-10-16** — The signature landing detail is a cropped, offset resume-analysis proof surface aligned to a quiet process grid; decoration must reinforce product evidence.
- **2026-10-16** — Motion stays restrained, with reduced-motion parity.

- **2026-10-16** — Preserve the established page composition and navigation styling. The user prefers the original visual style, so future usability fixes should be narrow rather than broad structural revamps.
