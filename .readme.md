# 4. ATS READINESS CHECKER

Route: `/candidate/resume/ats-checker`

Implement a real ATS readiness assessment.

Evaluate whether the resume is easy to parse, logically organized, and contains relevant career information.

## Scoring Criteria

Use an explainable scoring system:

| Component | Weight |
|---|---:|
| Text Extraction and Parseability | 30% |
| Resume Section Structure | 25% |
| Contact and Professional Information | 15% |
| Skills and Experience Evidence | 20% |
| Content Clarity and Consistency | 10% |
| **Total** | **100%** |

Make criteria configurable and document the scoring formula.

### A. Text Extraction and Parseability — 30%

Evaluate:
- Whether useful text can be extracted.
- Whether the extraction appears complete.
- Whether words and section headings are readable.
- Whether important information is preserved.

Flag detectable parsing issues.

Do not claim that columns, tables, fonts, or images are problematic unless the system can reliably detect a relevant issue.

### B. Resume Section Structure — 25%

Check for recognizable sections such as:
- Professional Summary.
- Skills.
- Education.
- Experience or Projects.
- Certifications, where relevant.

Use flexible heading detection.

Support fresh graduates whose project experience may be more relevant than employment history.

### C. Contact and Professional Information — 15%

Check whether essential professional contact information is available and parseable.

Do not require:
- Date of birth.
- Gender.
- Photograph.
- National identity number.
- Marital status.
- Home address.

### D. Skills and Experience Evidence — 20%

Evaluate whether the resume clearly describes relevant skills and gives supporting examples through projects, employment, internships, or certifications.

Do not require previous full-time employment for a fresh graduate to receive a reasonable score.

### E. Content Clarity and Consistency — 10%

Check for:
- Readable section boundaries.
- Excessive repeated content.
- Unclear abbreviations.
- Inconsistent or missing dates when dates are provided.
- Weakly described responsibilities or project outcomes.

Do not deduct points solely because of personal writing style, background, or institution prestige.

## Score Interpretation

Display these configurable guidance categories:

- 85–100: Strong Readiness
- 70–84: Good Readiness
- 50–69: Needs Improvement
- 0–49: Significant Improvements Suggested

Explain prominently:

"This is SkillBridge AI's estimated resume readiness score, not an official score from a commercial ATS. Different employers and recruitment systems may process resumes differently."

# 5. RESUME-TO-JOB DESCRIPTION MATCHING

Route: `/candidate/resume/job-match`

Build a second scoring engine that evaluates how closely resume content aligns with a specific job description.

This score must be separate from the ATS readiness score.

## Job Description Input

Provide three options:

1. Select an existing job from SkillBridge AI.
2. Paste a job description manually.
3. Use a demonstration job description.

### Matching Criteria

| Criteria | Weight |
|---|---:|
| Required Skills Alignment | 40% |
| Preferred Skills Alignment | 15% |
| Relevant Experience / Project Evidence | 20% |
| Responsibilities and Competency Relevance | 15% |
| Relevant Education / Certification Requirements | 10% |
| **Total** | **100%** |

Only score education and certifications where the job genuinely specifies those requirements.

Redistribute non-applicable weights instead of penalizing candidates for requirements that are not present.

Support suitable alternatives and transferable skills.

The system must distinguish:
- Skills mentioned.
- Skills supported by project or experience evidence.
- Skills missing from the resume.
- Skills that may be present but have not been recognized.

A missing keyword should not automatically mean the candidate lacks the underlying ability.

## Matching Engine

The backend should:

1. Extract resume text.
2. Parse the job description.
3. Identify job-related competencies.
4. Normalize skill terminology.
5. Compare required skills.
6. Compare preferred skills.
7. Analyze relevant experience and projects.
8. Calculate the alignment score.
9. Identify relevant missing or unclear information.
10. Generate evidence-based improvement feedback.

Reuse the existing SkillBridge skill taxonomy and alias database.

For example:
- JS = JavaScript.
- React.js = React.
- PostgreSQL is related to SQL but is not automatically equivalent to all database competencies.

Avoid superficial keyword counting where possible.

Implement transparent, deterministic rules for the initial MVP.

Optional semantic similarity may enhance the system, but essential matching must function without external AI services.

# 7. RESUME IMPROVEMENT ASSISTANT

Route: `/candidate/resume/improve`

Develop a contextual resume improvement module.

The system should help candidates strengthen how they present existing, genuine experience.

## Features

### Resume Summary Improvement
Analyze the candidate's current summary and provide a clearer alternative based only on confirmed information.

### Experience Bullet Improvement
Suggest clearer, more specific descriptions.

Preserve facts.

Never invent:
- Employment history.
- Certifications.
- Responsibilities.
- Performance improvements.
- Quantified achievements.
- Technologies used.

### Job-Specific Resume Suggestions
Suggest:
- Relevant existing skills to emphasize.
- Projects to highlight.
- Missing details to clarify.
- Job terminology to use when factually appropriate.

### ATS-Friendly Structure Guidance
Provide:
- Commonly recognized section headings.
- Readable text organization.
- Clear project and experience descriptions.
- Suggestions to improve extraction issues detected by the parser.

Make recommendations editable and allow candidates to accept or reject them.

## Optional Generative AI

If a provider API key is configured, optionally generate more natural writing suggestions.

If no API provider is available:
- Show rule-based recommendations.
- Preserve existing resume checking functionality.
- Do not show fake AI-generated feedback.

Protect private resume content and obtain consent before sending it to an external AI provider.
